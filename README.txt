DoE stories and statistics — standalone

This folder is the page at stories_and_statistics.html, including the One-Way ANOVA section.
It does not need the rest of the course, an internet connection, or any install if you only open the HTML file.

On this computer or another one:

1. Copy this whole folder (or the zip) onto the other PC.
2. Mac: double-click "Start ANOVA.command".
   Windows: double-click "Start ANOVA.bat".
   The page opens at the One-Way ANOVA section.
   Leave the black window open while you read. Close it when you are done.
3. If Python is not installed, double-click stories_and_statistics.html instead.
   Then click "One-Way ANOVA" in the top bar.

The launcher uses only the Python that comes with macOS, or Python on Windows if it is already installed.
Nothing is downloaded.
